# GIS Portfolio: The Power of Where

A collection of maps and GIS exercises built in ArcGIS Pro, covering data preparation, symbology, labelling, and map layout for clear communication.

- **GitHub:** [MumbaMumba789/Spatial-Mapping](https://github.com/MumbaMumba789/Spatial-Mapping)
- **Map 1 data (Google Drive):** [Map 1 files](https://drive.google.com/drive/folders/1Rf7AqHi-2kkEbUVQfsk9ZXIQn6YOoX48?dmr=1&ec=wgc-drive-%5Bmodule%5D-goto)

## Contents

| Project | Description | Status |
|---|---|---|
| [Making a Map in ArcGIS](Making%20a%20Map%20in%20arcgis/) | Mapping London Underground station usage (Tube foot traffic, 1 to 7 June) for decision-makers | In progress |

## Folder structure

```
portfolio/
├── README.md                      <- you are here
└── Making a Map in arcgis/        <- Project 1: London Underground foot traffic
    ├── README.md                  <- project overview, steps, and data sources
    ├── data/
    │   ├── raw/                   <- original downloaded data, never edited
    │   └── processed/             <- cleaned or joined data used in the map
    ├── project/                   <- ArcGIS Pro project (.aprx) and geodatabase (.gdb)
    ├── layouts/                   <- final exported map layouts (PDF / PNG)
    └── screenshots/               <- progress screenshots for the portfolio
```

## Tools

- ArcGIS Pro
- Esri training: *The Power of Where: Communicating with Maps*

## Notes

- Raw data is kept separate from processed data so every step can be repeated.
- Project 1 is designed as a template: the same layout can be reused for a weekly map series.
